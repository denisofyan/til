# TIL

> Today I Learned — small things I pick up along the way.

A growing collection of short notes on Web3, Python, Linux, and developer tooling. Most entries are 3-5 sentences. The goal is to **write it down before I forget** — turning fleeting "oh that's neat" moments into a searchable archive.

## Index

Notes are grouped by topic under `notes/`:

- [`notes/web3/`](notes/web3) — EVM, on-chain tooling, DeFi mechanics
- [`notes/python/`](notes/python) — stdlib tricks, packaging, async patterns
- [`notes/linux/`](notes/linux) — shell, systemd, networking
- [`notes/tooling/`](notes/tooling) — git, neovim, terminal multiplexers
